# 命令参考

## 帮助

```sh
ztedbcli
ztedbcli help
ztedbcli -h
ztedbcli --help
```

## 诊断初始化

```sh
ztedbcli diag
```

`diag` 用于排查 `DBShmCliInit failed`。它会按顺序检查：

- `dlopen("libifscfapi.so")`
- `dlopen("libcfapi.so")`
- `dlopen("libdbcspview.so")`
- `shmget(0xffff, 0, 0)`
- `shmat(shmid, 0x60000000, 0)`
- `DBShmCliInit()`
- `dbFindTbl("TelnetCfg")`

示例：

```sh
LD_LIBRARY_PATH=/lib:/usr/lib /tmp/ztedbcli diag
```

如果某个库缺失或符号解析失败，stderr 会直接显示动态链接器返回的错误。 如果三个库都成功，但 `shmget key=0xffff` 失败，说明当前进程没有看到 `cspd`/DB server 创建的 SysV shared memory。如果 `DBShmCliInit()` 返回 非零但 `dbFindTbl TelnetCfg OK`，说明运行时 DB 实际可用，该返回值只作为 warning 处理。

## 打印表

打印指定表：

```sh
ztedbcli TelnetCfg
ztedbcli p TelnetCfg
ztedbcli print TelnetCfg
```

一次打印多张表：

```sh
ztedbcli TelnetCfg WLANBase WLANCfg WLANPSK GPONCFG
```

输出为 XML：

```xml
<RuntimeDB>
  <Tbl name="TelnetCfg" RowCount="1">
    <Row No="0">
      <DM name="Lan_Enable" val="1"/>
    </Row>
  </Tbl>
</RuntimeDB>
```

## 批量 dump

使用程序内置表名清单：

```sh
ztedbcli dump -o /tmp/runtime-db.xml
```

使用外部表名清单：

```sh
ztedbcli dump -f /tmp/db-table-list.txt -o /tmp/runtime-db.xml
```

表名文件格式是一行一个表名，空行和 `#` 注释会被忽略：

```text
# common tables
TelnetCfg
WLANBase
WLANCfg
WLANPSK
GPONCFG
```

导出结束后，程序会向 stderr 打印统计摘要，不会写入 XML：

```text
dump summary: total=412 ok=194 failed=218
```

其中 `total` 是本次尝试导出的表数，`ok` 是成功导出的表数，`failed` 是缺表、 缺行或字段读取失败的表数。

## 读取字段

```sh
ztedbcli get Table Row DM
```

示例：

```sh
ztedbcli get TelnetCfg 0 Lan_Enable
ztedbcli get DevAuthInfo 0 Pass
```

返回值直接打印到 stdout。如果表、行或字段不存在，会返回非零退出码并在 stderr 打印错误。

实现上，`get` 和 `print` 使用同一条低层路径：先 `dbFindTbl()` 找表，再用 `dbFindRowByNo()` 按行号取行，然后匹配字段名并调用 `dbGetDmValComm()` 取值。 这样可以避开部分固件中 `dbGetValComm()` 返回空值，以及直接遍历行链表导致 多行表崩溃的问题。

## 修改字段

```sh
ztedbcli set Table Row DM Value
```

示例：

```sh
ztedbcli set TelnetCfg 0 Lan_Enable 1
ztedbcli set DevAuthInfo 0 Pass new_password
```

注意：`set` 只修改运行时共享内存，不自动落盘。

## 添加行

```sh
ztedbcli addrow Table
ztedbcli addr Table
```

示例：

```sh
ztedbcli addrow WLANCfg
```

## 删除行

```sh
ztedbcli delrow Table Row
ztedbcli delr Table Row
```

示例：

```sh
ztedbcli delrow WLANCfg 3
```

## 保存

```sh
ztedbcli save
```

`save` 默认调用设备上的原厂命令：

```sh
sendcmd 1 DB save
```

成功时输出：

```text
OK save via sendcmd
```

`dbAPISave()` 在部分固件中依赖 ZTE 进程内的消息上下文，独立进程直接调用可能 段错误。`ztedbcli save-direct` 仅用于诊断：它会在子进程里尝试直接调用 `dbAPISave()`，即使崩溃也不会拖垮主进程。

建议保存后执行：

```sh
sync
```

## 和 sendcmd 命令对照

| sendcmd | ztedbcli |
| --- | --- |
| `sendcmd 1 DB p TelnetCfg` | `ztedbcli p TelnetCfg` |
| `sendcmd 1 DB get DevAuthInfo 0 Pass` | `ztedbcli get DevAuthInfo 0 Pass` |
| `sendcmd 1 DB set DevAuthInfo 0 Pass new_password` | `ztedbcli set DevAuthInfo 0 Pass new_password` |
| `sendcmd 1 DB set TelnetCfg 0 Lan_Enable 1` | `ztedbcli set TelnetCfg 0 Lan_Enable 1` |
| `sendcmd 1 DB addr WLANCfg` | `ztedbcli addrow WLANCfg` |
| `sendcmd 1 DB delr WLANCfg 3` | `ztedbcli delrow WLANCfg 3` |
| `sendcmd 1 DB save` | `ztedbcli save` |

## 常见命令

```bash
# 查看 loid
ztedbcli p PDTCTUSERINFO 
ztedbcli get PDTCTUSERINFO 0 UserName

# 查看 EPON信息
ztedbcli p EPONProduct 
ztedbcli get EPONProduct 0 OnuLoid
ztedbcli get EPONProduct 0 OnuSn
ztedbcli get EPONProduct 0 LoidPasswd

# 查看 GPON信息
ztedbcli p GPONCFG

ztedbcli get GPONCFG 0 Password


# 查看 WANCPPP 拨号信息
ztedbcli p WANCPPP

ztedbcli get WANCPPP 0 Password

# 查看 WAN 信息 包含IPTV和电话配置
## 1_TR069_R_VID_46 
## 2_INTERNET_R_VID_41
ztedbcli p WANC 
```

## 推荐操作顺序

修改前：

```sh
ztedbcli get TelnetCfg 0 Lan_Enable
ztedbcli get DevAuthInfo 0 Pass
ztedbcli p TelnetCfg > /tmp/TelnetCfg.before.xml
ztedbcli p DevAuthInfo > /tmp/DevAuthInfo.before.xml
```

修改：

```sh
ztedbcli set TelnetCfg 0 Lan_Enable 1
ztedbcli get TelnetCfg 0 Lan_Enable
ztedbcli set DevAuthInfo 0 Pass new_password
ztedbcli get DevAuthInfo 0 Pass
```

确认无误后保存：

```sh
ztedbcli save
sync
```
